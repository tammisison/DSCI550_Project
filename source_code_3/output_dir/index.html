Multimodal Haunted Places Data Analysis

Interactive visualizations of haunted places across the United States

Project Overview

This project analyzes haunted places data across the United States, exploring patterns in reported hauntings, types of apparitions, and correlations with geographic and temporal factors. The visualizations provide interactive ways to explore the data and discover insights about paranormal phenomena.

How to Use This Project

  1. Browse the visualizations below by clicking on any of the cards
  2. To set up the docker environment for Solr and ElasticSearch:
    • Go to the docker folder
    • Run start_services.bat (Windows) or ./start_services.sh (Mac/Linux)
    • After services start, run import_data.bat or ./import_data.sh to import data
  3. For MEMEX GeoParser, use the geoparser_input.txt file with the GeoParser application

External Tools

This project also integrates with the following MEMEX tools:

  • MEMEX ImageSpace - For exploring similarities between haunted place images
  • MEMEX GeoParser - For extracting and visualizing geographic information

Data from this project has been prepared for these tools and can be accessed in the output directory.
